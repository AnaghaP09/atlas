# Automatic runs

## What this page is for

This page lists the watchers and schedules that start runs on their own.

## Who uses it

Engineering manager and audit.

## How to use it

1. Read each line. It shows the state, the last run and the next run.
2. Turn a watcher on, pause it, or run it once.

## The watchers

| Watcher | Starts a run when |
|---|---|
| Release watcher | A new release tag appears. |
| Failure watcher | A new failure appears. |
| Nightly sweep | The set time arrives each night. |
| Question summary | The schedule says so. It is off by default. |

In Offline mode, watchers that need the internet pause and say why.
