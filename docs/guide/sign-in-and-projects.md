# Sign-in and projects

## What this page is for

This page explains how you sign in and how you choose a project.

## Who uses it

Every role.

## How to use it

1. Open ATLAS in your browser.
2. Choose your role, or sign in with a demo user. The table below explains which.
3. Choose the project in the top bar.

## Sign-in

| Way to run ATLAS | How you choose a role |
|---|---|
| Simple local server | A role switcher in the top bar. There is no password. |
| Local site with sign-in | A user name and password. Setup creates one demo user for each role. |

Neither way is a real company sign-in. That is not in this build.

## Projects

A project is one set of sources that ATLAS reads. ATLAS keeps each project's data apart.

| Project | What you can use |
|---|---|
| KubeVirt | Everything, including the quality checks. |
| Argo CD | Live views and reports only. |

You can add your own projects. See [Install ATLAS on your own machine](install.md).
