# Product manager

## What you see

You see the forecast report. It lists the technical debt and issues that the next release is likely to inherit. Each item has a cost now, a cost if you wait, and links to the evidence.

## What you decide

- Which debt goes into the next release.
- How much time the release spends on debt.
- What to cut, and the release date.

ATLAS never makes these decisions.

## What you do in ATLAS

1. Open the forecast report after a release close.
2. Open the evidence for any item you doubt.
3. Record your decisions on the Record a decision page.
4. Start a run by hand when you need a fresh forecast.
