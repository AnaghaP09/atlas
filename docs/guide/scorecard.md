# Scorecard

## What this page is for

The scorecard shows whether the coding agent helped. It compares the agent's tasks with similar tasks done by people.

## Who uses it

Engineering manager and audit.

## How to use it

1. Read each row. A row is one kind of task.
2. Check the label on the comparison data.

## Good to know

- The comparison data for people is sample data in this build. The page says so.
- If there is no fair comparison, the result shows as unavailable.
- A result can be negative. ATLAS shows it.
