# Engineering manager

## What you see

You see the allocation report. It suggests who should take each item: a developer, the coding agent, or a person who must decide. You also see the tasks given to the coding agent.

## What you decide

- What to hand to the coding agent.
- What to give to a developer.
- Whether to approve a code change. Every change needs your approval twice.

## What you do in ATLAS

1. Read the allocation report.
2. Answer the items on the Needs a person page.
3. Give Approval A to let the coding agent prepare a change.
4. Read the exact change. Then give or refuse Approval B.
5. Decide whether the finished fix is correct on the Tasks page.
6. Turn automatic runs on or off.

Some items belong to another role. They show as locked. Select **Request access** to ask for read-only access. See [Access requests](access-requests.md).
