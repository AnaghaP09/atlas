# Solution architect

## What you see

You see the architecture report. It shows the parts of the system with the most debt and the links between parts.

## What you decide

- Which debt to accept, with a written reason.
- Which debt to fix.
- Which earlier design decisions to review.

## What you do in ATLAS

1. Read the architecture report.
2. Use the knowledge graph to see which parts depend on a weak part.
3. Record each debt decision and its reason.

## If a page or item is locked

Some items belong to another role. They show as locked. Select **Request access** to ask for read-only access. See [Access requests](access-requests.md).
