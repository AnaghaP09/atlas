# On-call engineer

## What you see

You see investigation reports. Each one names the likely cause of a failure and links to the evidence. If the evidence is not enough, the report says so and lists what is missing.

## What you decide

- Whether the cause is right.
- What to do next: fix now, wait, or pass the problem to the owning team.

## What you do in ATLAS

1. Open the investigation report for a failure.
2. Check the cited logs and changes.
3. Start an investigation by hand if ATLAS has not started one.

## If a page or item is locked

Some items belong to another role. They show as locked. Select **Request access** to ask for read-only access. See [Access requests](access-requests.md).
