# Notifications

## What this page is for

This page lists errors, reminders and decisions. ATLAS sends each one to the roles that need it.

## Who uses it

Every role.

## How to use it

1. Read the most serious items first.
2. Select an item to open the run or task behind it.
3. Mark it as read, or as solved.

## Good to know

- Every error creates a notification. No error ends in silence.
- ATLAS can also send notifications to a chat address. This is off until you set the address and say who reads that channel.
