# Security engineer

## What you see

You see the security gate report. It shows the result of the security check and any finding that blocks a change. You can read the kill switches but you cannot resume them.

## What you decide

- Whether a blocking finding stops a change.
- Whether to allow an exception. An exception needs a written record.

## What you do in ATLAS

1. Read the security gate report.
2. Answer the security items on the Needs a person page.
3. Watch the kill switches after a safety event.

| Page | Why you use it |

## Requests that wait for you

Requests to read security findings or the security gate report wait for your decision. They appear in your notifications.

## If a page or item is locked

Some items belong to another role. They show as locked. Select **Request access** to ask for read-only access. See [Access requests](access-requests.md).
