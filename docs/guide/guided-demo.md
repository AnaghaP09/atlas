# Guided demo

## What this page is for

The guided demo walks through each part of ATLAS in order.

## Who uses it

Audit.

## How to use it

1. Start the demo.
2. Follow each step. The page names the part of ATLAS that the step shows.
3. Some steps need the second demo server. The page sends you there.

## Good to know

The second server is called the scenario server. It has its own data. It can create test faults, so the kill switches can be shown safely.
