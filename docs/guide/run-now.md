# Run now

## What this page is for

Use this page to start a run by hand. A run started by hand gets the same checks, limits and audit record as an automatic run.

## Who uses it

Product manager, engineering manager, on-call engineer and audit.

## How to use it

1. Choose the kind of run: release close, investigation, nightly sweep, question, or a new check of an earlier run.
2. Fill in the fields. The page shows only the fields that the run needs. One field is **Data as of**. See [Data as of](data-as-of.md).
3. Select the button to start. ATLAS opens the run so you can follow it.

## Good to know

A button can be off. The page then says why. Common reasons are Offline mode, a kill switch, or the spend ceiling.
