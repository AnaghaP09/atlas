# Access requests

## What this is

Each role sees only its own pages and items. Sometimes an item links to another item that your
role cannot open. ATLAS shows that item as locked, with a **Request access** button.

An access request asks to read one locked item. Read-only access means that you can read the
item but you cannot change it.

## How to ask

1. Select **Request access** on the locked item.
2. Write why you need it. This is optional.
3. Send the request.

What happens next depends on the kind of item.

| Kind of item | Examples | What happens |
|---|---|---|
| Ordinary | Reports, tasks, approvals, the knowledge graph, runs, scorecard rows | The item opens at once. You can read it for 24 hours. ATLAS tells the role that owns the item. That role can withdraw the access at any time. |
| Sensitive | Security findings, the security gate report, kill-switch incidents, audit pages | The request waits. The security role or the audit role decides. ATLAS tells you the answer in your notifications. |

## What access never allows

Access is for reading only. It never lets you:

- approve or reject anything;
- publish anything;
- change anything.

## Good to know

- Access covers one item, not a whole page.
- Access ends after 24 hours. Ask again if you still need it.
- ATLAS keeps a record of every request, every answer and every withdrawal.
