# Tasks

## What this page is for

A task is one small code change given to the coding agent. This page follows each task from the first proposal to the final decision on whether the fix is correct.

## Who uses it

Engineering manager and audit.

## How to use it

1. Select a task to see its state, its checks and its test results.
2. Open the draft pull request.
3. When the tests have run, record whether the fix is correct.

## Good to know

- ATLAS opens draft pull requests only on the sandbox repository. It never merges.
- A task counts as accepted only after the tests pass and a person says the fix is correct.
- Tests on the full upstream project are not in this build.
