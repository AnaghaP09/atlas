# Knowledge graph

## What this page is for

The knowledge graph is a map of the system's parts, the teams that own them, and the links between parts.

## Who uses it

Solution architect and audit.

## How to use it

1. Choose the data to show, under **Data as of**. See [Data as of](data-as-of.md).
2. Select a part to see what depends on it.

## Good to know

ATLAS builds the links from the import statements in the code. Links that exist only when the system runs are marked as unknown.
