# Live dashboard

## What this page is for

The live dashboard shows new issues, test results and releases from the project's public sources.

## Who uses it

Every role.

## How to use it

1. Read the newest items at the top.
2. Select an item to see the exact record that ATLAS read.
3. Check the refresh interval shown on the page.

## Good to know

- ATLAS asks GitHub for changes at a fixed interval. The data is as recent as the last check. It is not instant.
- The dashboard needs a GitHub token. See [Install ATLAS on your own machine](install.md).
- In Offline mode the dashboard stops updating and says why.
