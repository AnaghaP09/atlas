# ATLAS — agentic engineering control plane (capstone backend)

ATLAS predicts the technical debt and issues the next release will inherit from the current one,
proposes how to allocate that work across coding agents, developers and decision makers,
investigates mid-release failures with cited evidence, and hands approved, bounded tasks to a
sandboxed coding agent. It is domain- and product-agnostic; the reference ecosystem for the demo is
the public KubeVirt project.

Status: planning. The build starts after the plan is approved. A web UI will sit on top of the
backend's HTTP API (see `ui/`).
